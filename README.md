# Zarp — сайт сервиса

Рекламный сайт на **React + Vite + TypeScript**, созданный на основе официального шаблона `react-ts`. Тёмная тема, локальный шрифт Manrope, адаптивная вёрстка, скриншоты приложений, FAQ и ссылки на официальные загрузки.

## Локальный запуск

Требуется Node.js 24 LTS.

```sh
npm ci
npm run dev
```

В PowerShell при ограничении запуска `.ps1` используйте `npm.cmd` вместо `npm`.

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. `base: './'` позволяет разместить её в корне домена или в подкаталоге GitHub Pages. Файлы `dist/` не нужно добавлять в репозиторий: GitHub Actions собирает их самостоятельно.

## GitHub Pages

1. Создайте репозиторий сайта (например, `ZarpVPN/ZARPSite`) и загрузите исходники в ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` устанавливает зависимости, проверяет TypeScript, собирает сайт и публикует `dist/` после каждого push в `main`. Если первый запуск был до включения Pages, запустите workflow вручную во вкладке Actions.
4. URL появится в **Settings → Pages** и в результате workflow. Для репозитория `ZarpVPN/ZARPSite` обычно это `https://zarpvpn.github.io/ZARPSite/`.
5. Добавьте этот URL в поле **Website** раздела **About** репозитория и в профиль организации.

Официальные инструкции: [GitHub Pages workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [Vite static deploy](https://vite.dev/guide/static-deploy.html).

## Содержимое и релизы

- `src/data.ts` — описания платформ, требования, FAQ и резервные ссылки на релизы.
- `src/useReleases.ts` — обновление ссылок через публичный GitHub API. API возвращает последние стабильные релизы; APK и DMG подбираются по реальному имени файла. При сетевой ошибке или лимите GitHub остаются проверенные резервные ссылки. Ключи и сервер не нужны.
- `src/App.tsx` — блоки сайта и интерактивные элементы.
- `src/App.css`, `src/index.css` — адаптивная вёрстка и тема.
- `src/motion.css` — плавные переходы скриншотов, FAQ, меню и интерактивных элементов. Базовый размер `rem` адаптируется к ширине окна: композиция сохраняет пропорции на широких экранах и при масштабировании браузера. Шапка масштабируется отдельно и остаётся компактной.
- `public/assets/` — настоящие скриншоты из репозиториев проекта.
- `src/HeroLayers.tsx`, `src/HeroLayers.css` — прежняя композиция из отдельных слоёв: точечная сфера, орбита, карточка и плашки. Лёгкий параллакс следует за мышью через CSS transition. На сенсорных устройствах и при reduced motion слои неподвижны.

Карточка первого экрана декоративная, без кнопки подключения и имитации работы VPN. Настоящие кнопки ведут к загрузке приложений и исходному коду; при наведении плавно приподнимаются без смены цвета.

Источники описаний: README трёх приложений, [профиль организации](https://github.com/ZarpVPN/.github/blob/main/profile/README.md), release notes. Утверждения о приватности относятся к Zarp; WARP работает по условиям Cloudflare. Маршрутизация и собственные серверы представлены с учётом различий платформ. На сайте нет аналитики, cookies, вымышленных отзывов и статистики скорости.

Шрифт размещён локально; лицензия OFL находится в пакете `@fontsource-variable/manrope`. Иконки скачаны из Tabler Icons и SVG Repo и хранятся локально; источники и лицензии перечислены в `public/assets/icons/SOURCES.md`. Скриншоты принадлежат проекту Zarp. Сведения о лицензиях приложений и встроенных компонентов доступны в их репозиториях.
